# Text Analysis

## Veda Technology – AI & ML Internship

### Day 6 – Task 6

This project performs basic text analysis using Python.

The application analyzes a given text and calculates:

- Total number of words
- Total number of characters
- Characters excluding spaces
- Total number of vowels
- Frequency of individual vowels
- Repeated words and their frequencies

## Objective

The objective of this project is to practice basic text-processing techniques that are useful for Natural Language Processing (NLP).

## Technologies Used

- Python
- Jupyter Notebook
- Streamlit
- Collections Counter
- Regular Expressions

## Features

### 1. Word Count

Counts the total number of words present in the input text.

### 2. Character Count

Calculates the total number of characters.

### 3. Vowel Analysis

Counts the total number of vowels and provides individual vowel frequencies.

### 4. Repeated Word Detection

Identifies words that appear more than once and displays their frequency.

### 5. Case-Insensitive Analysis

Converts the text to lowercase so that words such as Python, PYTHON and python are treated as the same word.
